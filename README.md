# Web Development Project

This project was created as part of a **Web Development class** at Southern Utah University.  
It demonstrates the use of **HTML, CSS, and JavaScript** to build a responsive website with multiple pages and features.

## Features
- Home page with navigation
- About page
- Portfolio pages (individual student contributions)
- Contact form
- Styling with CSS
- Basic JavaScript for interactivity

## Technologies Used
- HTML5
- CSS3
- JavaScript
